# Telecommunications

Telecommunications tracks cover the network and voice protocols that underpin automation and application delivery in enterprise environments.

## Subdomains
- [Networking](./networking/README.md) — foundations, services, routing, switching, and QoS.
- [Voice](./voice/README.md) — VoIP, SIP, RTP, and transport topics.

## Suggested Order
1. Start with [Networking Overview](./networking/00_networking_overview.md) to build IP foundations.
2. Work through DNS, DHCP, routing, and switching.
3. Move to [Voice Overview](./voice/00_voice_overview.md) once IP fundamentals are solid.
4. Cover SIP signaling, RTP media, and transport concerns.
