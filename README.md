# Teaching

A domain-based learning library for automation engineers, programmers, network operators, and voice teams who need to close practical skill gaps.

## Root Domains
- [Coding](./coding/README.md) — Python, SQL, APIs, automation tooling, and cloud operations.
- [Telecommunications](./telecommunications/README.md) — networking foundations, routing, switching, QoS, VoIP, SIP, and RTP.
- [AI](./ai/README.md) — using AI agents effectively: prompting, spec building, and planning.
- [Project Management](./project_management/README.md) — SDLC habits, Jira usage, and team execution workflows.

## Recommended Starting Paths
### For network engineers building automation skills
1. [Coding / Python Basics](./coding/python/basics/README.md)
2. [Coding / API REST](./coding/api/rest/README.md)
3. [Project Management / SDLC for Automators](./project_management/01_sdlc_for_automators.md)

### For programmers closing networking and voice gaps
1. [Telecommunications / Networking Overview](./telecommunications/networking/00_networking_overview.md)
2. [Telecommunications / Networking Services](./telecommunications/networking/services/README.md)
3. [Telecommunications / Voice Overview](./telecommunications/voice/00_voice_overview.md)

### For everyone on the team
1. [Coding](./coding/README.md)
2. [Telecommunications](./telecommunications/README.md)
3. [AI](./ai/README.md)
4. [Project Management](./project_management/README.md)

## Notes
- The repository is organized by operational domain instead of language-only silos.
- Examples, exercises, and solutions are included so learners can practice instead of just reading.
- `.github/workflows/monthly-ai-update.yml` opens a monthly Copilot audit issue to keep lessons current.
