# Azure Overview

## Overview
Azure is common in enterprise application environments that need strong identity integration, managed app platforms, and broad regional coverage.

## Key Services For App Teams
- Virtual Machines for host-based workloads
- App Service for managed web applications
- AKS for Kubernetes workloads
- Azure SQL for managed relational databases
- Storage Accounts for blobs, files, and queues
- Entra ID and RBAC for identity and access control

## Exercises
1. Name one managed web hosting option in Azure.
2. Which service usually fits relational SQL workloads?
3. Why does identity design matter even on managed platforms?

## Answer Key
1. App Service is a common managed hosting choice.
2. Azure SQL is a common relational option.
3. The platform is only safe when access is scoped correctly.
