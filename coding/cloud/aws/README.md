# AWS

Practical AWS lessons for application teams and DevOps engineers who need managed databases and container platforms without losing operational control.

## Focus Areas
- [RDS](./rds/README.md) — managed PostgreSQL and MySQL operations, backups, scaling, and production tuning.
- [ECS](./ecs/README.md) — container orchestration on AWS with a Fargate-first deployment model.

## How to Use
1. Start with the overview lesson for each sub-module.
2. Run the examples to see production-oriented defaults.
3. Complete the exercises before reviewing the solutions.

## Practice Assets
- `rds/examples/`, `rds/exercises/`, `rds/solutions/`
- `ecs/examples/`, `ecs/exercises/`, `ecs/solutions/`
