# Jira Usage for Engineering Workflows

## Overview
Jira is most useful when it reflects real work clearly enough for the team to plan, execute, and review progress without turning into busywork.

## Good Ticket Habits
- Use clear titles with the problem and affected area.
- Record acceptance criteria.
- Link related incidents, PRs, or follow-up tasks.
- Keep status changes honest and current.
- Capture blockers explicitly instead of hiding them in comments.

## Automation-Friendly Usage
- Break large automation efforts into small tickets with testable outcomes.
- Track risk, rollout steps, and validation notes.
- Use labels or components for domains like coding, networking, voice, or cloud.

## Exercises
1. Explain why acceptance criteria matter.
2. Name one reason status accuracy matters in Jira.
3. Describe how labels can help an automation team.

## Answer Key
1. Acceptance criteria define what done looks like.
2. Accurate status helps planning, dependency tracking, and handoffs.
3. Labels make it easier to group work by domain or platform.
