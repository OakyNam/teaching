# GCP Overview

## Overview
GCP is strong in managed application hosting, data analytics, Kubernetes, and service-to-service identity patterns.

## Key Services For App Teams
- Compute Engine for VMs
- Cloud Run for container-based serverless apps
- GKE for Kubernetes workloads
- Cloud SQL for managed relational databases
- Cloud Storage for object storage
- IAM for identity and authorization

## Exercises
1. Name one serverless app hosting option in GCP.
2. Which managed database service fits relational app workloads?
3. Why should teams still care about IAM on managed services?

## Answer Key
1. Cloud Run is a common serverless hosting choice.
2. Cloud SQL fits many relational workloads.
3. Managed services still need correct access boundaries and least privilege.
